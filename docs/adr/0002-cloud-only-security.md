# ADR 0002 — 클라우드 전용 보안 모델 (유출가능만)

- **상태**: accepted
- **날짜**: 2026-07-29

## 배경

모바일은 임베딩·생성 모두 클라우드로 전송. 데스크탑판의 핵심 보안(유출불가 문서는 클라우드 미전송, 로컬 LLM으로만)이 모바일엔 성립 불가 — 로컬 LLM이 없기 때문.

## 결정

- **유출불가(confidential) 문서는 업로드 자체를 금지.** 모바일에선 어떤 문서든 클라우드로 나가므로, 나가면 안 되는 문서는 받지 않는다.
- 벡터DB는 **단일 컬렉션**(유출가능 전용). 데스크탑의 all/leakable 2컬렉션 분리 불필요.
- 업로드 UI는 "유출가능 문서만 업로드하세요" 명시 + (가능하면) 사용자 확인.

## 대안

- 유출불가도 받되 클라우드 미전송 — 로컬 LLM 없어 답변 생성 불가. 무의미. 기각.
- 모바일에서 로컬 임베딩만 로컬 처리 — 생성은 결국 클라우드 전송 필요. 반쪽. 기각.

## 결과

- 장점: 단순·명확. "모바일=유출가능 전용" 규칙 하나로 누출 리스크 제거.
- 트레이드오프: 유출불가 문서는 데스크탑판에서만 사용. 두 앱 역할 분리.
